# Contributing compatibility evidence

Useful contributions answer five questions:

1. What exact app and workflow are being evaluated?
2. What does the vendor officially support today?
3. What is the best Omarchy route: native, web, bridge, or keep another OS?
4. What still needs a real machine, device, GPU, codec, plugin, font, or collaborator to test?
5. What should the user do if that test fails?

Use this template:

```text
App name:
Category:
Official compatibility source:
Omarchy path (native / web / bridge / blocked):
What must be tested:
Recommended migration plan:
```

Avoid unsourced compatibility claims, generic alternative lists, and “works for me” reports without the relevant hardware and workflow details.
